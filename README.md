# 📊 Import / Export Validation System

## 📌 Overview

An enterprise-grade data processing system for handling Excel imports, validation, transformation, and reporting.

---

## 🎯 Purpose

To demonstrate the ability to handle real-world data ingestion and processing scenarios.

---

## 🚀 Features

* Excel Upload (ClosedXML)
* Row-Level Validation
* Duplicate Detection (File & Database)
* Error Classification
* Preview Valid/Invalid Data
* Downloadable Error Reports
* Selective Data Persistence
* Export to Excel & PDF
* Background Processing (Hangfire)
* Audit Logging

---
